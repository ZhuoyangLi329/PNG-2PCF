# Task 4.3.2 controlled RSD closure contract

Status: execution complete.  The standard BAO-masked rawbox and lightcone
P/xi parameter-consistency analyses are numerically complete.  The lightcone
RSD xi multipole phase-shape test remains rejected, so this is not a full RSD
closure and Task 4.4 is not greenlit.

## Scientific question

Before interpreting the single-realization Task44 `fNL=100` LRG result, test
the same FullDiscrete Kaiser x Lorentzian-FoG monopole model on the 25
independent `AbacusSummit_base_c000_ph000..ph024` realizations with injected
`fNL=0`.

The existing Task43 real-space products are immutable controls.  Every new
file must live under an `rsd_validation` root and must never overwrite or move
an existing Task43 or Task44 artifact.

## Frozen inputs and conventions

- Tracer: halos with `Mmin=1.4e13 Msun/h`.
- Cosmology: AbacusSummit base `c000`.
- PNG response: `p_fixed=1` and injected `fNL=0`.
- Lightcone: `0.6 < z_obs < 0.8`, positive octant, `P0=10000`.
- Separation support: `s=30..350 Mpc/h`, `ds=10 Mpc/h`.
- Primary statistic: weighted Landy--Szalay `xi0`.
- Mandatory RSD diagnostic: `xi2`; rawbox also measures `P0/P2` when feasible.
- Canonical rawbox 2PCF fit selection: bin centers in `50 <= s < 350
  Mpc/h`, excluding `80 <= s < 120 Mpc/h` (26 of the 32 ten-Mpc/h
  bins).  The single source of truth is `rawbox_xi_primary_mask` in
  `task43_rsd_common.py`.
- The unmasked `smin` scan (`30, 40, 50, 80, 100, 120 Mpc/h`) is retained
  only as a frozen historical diagnostic; it is not the standard rawbox
  2PCF selection.
- Primary RSD model: FullDiscrete shell-averaged Kaiser x Lorentzian FoG with
  free `(b1, fNL, sigma_s)`.

The versioned standard rawbox inference entry point is
`task43_run_rawbox_baomask_mcmc_v1.py`.  It applies the same canonical mask to
real- and redshift-space `xi0`, refits both chains, and compares them against
the immutable P0 chains.  The older `task43_fit_rsd_rawbox_x25.py` and
`task43_fit_rsd_rawbox_pk0_vs_xi0_smin50.py` scripts reproduce the unmasked
baseline and must not be used for new standard rawbox 2PCF inference.

The standard full rawbox comparison is
`task43_run_rawbox_joint_baomask_v1.py`.  It fits real-space `P`, `xi`, and
their joint vector, and redshift-space `P0+P2`, `xi0+xi2`, and their joint
vector.  Both xi multipoles use the same canonical 26-bin BAO mask.  Its
strict cross-covariance is generated by the exact observed-P lattice modes
plus a positive-semidefinite xi-only mode complement; it applies neither an
empirical cross rescaling nor an eigenvalue floor.

## Coordinate mappings

The rawbox plane-parallel mapping uses the z axis:

`s_z = x_z + v_z / (VelZSpace_to_kms / BoxSize)` with periodic wrapping.

The lightcone mapping follows the radial AbacusHOD convention separately for
each source shell and observer origin:

`s = x + rhat * dot(v, rhat) / (VelZSpace_to_kms / BoxSize)`.

Candidates are read from a buffered true-redshift interval, mapped to
redshift space, converted to `z_obs`, and only then cut to `0.6 < z_obs < 0.8`.
The primary catalog follows the installed official cleaned loader: a non-zero
`pos_avg` selects `pos_avg/vel_avg`, while observer lookup independently uses
`origin % 3`; a legacy bridge quantifies the difference.

1. Synthetic mapping and atomic-I/O unit tests.
2. Rawbox zero-velocity bridge and `ph000` plane-parallel smoke.
3. Rawbox 3-phase pilot, then x25 closure.
4. Lightcone zero-velocity bridge and `ph000` radial-LOS smoke.
5. Lightcone 3-phase pilot, then x25 `xi0` production and `xi2` diagnostic.
6. RSD-multipole JAXpower raw covariance and RR deconvolution.
7. no-GIC and formal-GIC mean fits, frozen `smin` scan, per-phase profiles.
8. Only after the base closure passes: radial-IC or hybrid-GSM diagnostics.

core gate must produce `status=validation_failed`, not a successful closure.

## Statistical contract

- In the current standard rawbox inference, only the observed curve is the
  arithmetic mean of 25 realizations.  The likelihood, posterior, reported
  goodness-of-fit, and plotted error bars all use `C_single`; none is divided
  by 25 (or by sqrt(25) for errors).
- Earlier lightcone closure audits additionally reported a `C_mean =
  C_single/25` stress-test PTE and phase-level chi-squares.  Those fields are
  historical lightcone diagnostics and must not be imported into the standard
  rawbox likelihood or plots.
- Keep each covariance role explicit in named fields and metadata.
- Primary null gate: `abs(median(fNL)) / sigma68_single < 0.3`.
- Nominal mean/phase-level PTE gate: `PTE > 0.05`.
- Scale-stability target: nested-range parameter shifts below `0.3 sigma_ref`.
- MCMC gates: split-Rhat `<1.01`, post-burn length `>50 tau`, and half-chain
  shifts `<0.1 sigma`.
