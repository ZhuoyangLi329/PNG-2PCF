# Task 4.3.2：hybrid+GIC 的 joint b1 诊断

本轮结论与最终图件只使用 **1000 个 EZmock 的完整配对协方差**。执行过程中用户收窄了协方差范围；早期已经完成的 jaxpower 数值仅留在原始溯源文件，后续 runner 默认仅运行 EZmock1000。

主要发现是：**完整交叉协方差把一组相干的 xi0 残差投影成向下的共享 b1 位移，同时 P0 的常数项 sn0 补偿了部分振幅变化。** 这解释了联合最优点的移动机制，但没有证明交叉协方差错误，也没有单独证明 P 或 xi 哪一边的物理模型错误。

## 冻结口径和计算方式

- 数据：25 个 Abacus phase 的均值，沿用 9.18 的 P0 13 点、P2 9 点、xi0 26 点、xi2 26 点，共 74 维。
- 尺度：kmax=0.08，smin=50，保留原 80<=s<120 BAO mask。
- 正式基准模型：已验证 hybrid+确定性 GIC，xi0 减去同模型的完整窗口积分，xi2 不添加该标量项；没有增加 GSM 自由参数。
- 正式拟合使用 C_single 和完整交叉块。本轮主要数值为最大似然，不是新的 MCMC 边缘后验。
- 优化使用原先验；删点先截取协方差子块，再标准化 Cholesky 白化，未截取原 precision 子块。
- 交叉项扫描、固定 nuisance、拆分 b1、删点和壳平均均是诊断变体，没有替换原正式结果。
- 所有计算在登陆节点、同一组最多 8 个 CPU 上完成，无 Slurm 作业；数值库单线程。

## 定量结果

| 检查 | joint 最大似然 b1 | 解释 |
|---|---:|---|
| 正式基准 | 2.383164 | P-only=2.419496，xi-only=2.423165 |
| 交叉块乘 0 | 2.416067 | 交叉项贡献了大部分进一步向下偏移 |
| 交叉块乘 0.25 / 0.5 / 0.75 | 2.412764 / 2.407985 / 2.400315 | 随交叉相关增强持续下移 |
| 固定 fNL=0 | 2.381341 | 仍低于同一固定-fNL口径的 P=2.393444、xi=2.418271 |
| sigma_s_P 固定在 P-only 最佳点 | 2.383030 | 几乎不改变 b1 |
| sn0 固定在 P-only 最佳点 | 2.410927 | 明显回升，说明 P0 常数项参与退化 |
| 两个 P nuisance 都固定 | 2.416882 | 固定值的选择本身不是物理校准 |
| xi 球壳体积平均 | 2.387379 | 约 +0.0042，仍然偏低；此变体的 xi-only=2.431787 |
| 仅去掉 xi0 的 55、65、75 三点 | 2.405304 | 最小三个 xi0 bin 共同具有明显影响 |
| 仅去掉 xi2 的对应三点 | 2.386372 | 影响较小 |
| 去掉最高两个 P0 bin | 2.394024 | P0 较高 k 的宽带形状也参与偏移 |

在 P-only 最佳点线性化后，预测 joint b1=2.382122，与完整优化 2.383164 很接近。b1 线性位移按原始数据块分解为 P0=-0.002761、P2=-0.001043、xi0=-0.031897、xi2=-0.001673。这个分解依赖于线性化点与相关协方差，不能把各项当作独立因果效应。

局部归因中，xi0 的 55、65、75 三点合计贡献约 -0.01879，225、235 两点合计约 -0.01036。因此不能把所有偏移归因于最小尺度，后者的大尺度相干残差同样需要检查。

Schur 分解严格满足：

\[
\chi^2=r_P^T C_{PP}^{-1}r_P+
(r_\xi-C_{\xi P}C_{PP}^{-1}r_P)^T
S^{-1}(r_\xi-C_{\xi P}C_{PP}^{-1}r_P),
\quad S=C_{\xi\xi}-C_{\xi P}C_{PP}^{-1}C_{P\xi}.
\]

最大 P-xi 典型相关系数约 0.9598。强相关会让两种统计量的某些差分模式比各自单独的振幅更精确，因此联合参数的一维投影没有必须落在两个边缘最优点之间的数学要求。

拆分 b1 后，b1_P=2.393455、b1_xi=2.434243，差值 -0.040789；相对共享 b1 只改善原始 C_single chi2 约 0.528。其 C_single 局部 Fisher 差值误差约 0.056，不能据此忽略 25-phase 均值的更高检验精度。PDF 提供重新优化其他参数的 profile 曲线，未冒充新 MCMC。

## 协方差与 phase 稳定性

从完整的 1000 个配对 mock 中有放回抽样 300 次，每次重建全部 74x74 协方差并重新拟合 P、xi 和 joint。joint b1 的平均值为 2.3830、标准差为 0.00439，300/300 次都低于另外两组。这表明该中心偏移对这组 mock 的有限样本协方差噪声稳定，不证明协方差不存在共同系统误差。

25 个逐一去除 phase 的均值拟合中，joint b1 范围为 [2.37645,2.38751]，25/25 次都低于另外两组。因此没有证据表明问题由某个单独 phase 主导。这些 leave-one 均值高度相关，不能按 25 个独立检验计算显著性。

25-phase 散布在 EZmock 白化空间的协方差迹/74约为 1.049；投影到 joint b1 的经验方差约为协方差预测的 1.318 倍。样本量只有 25，本轮没有反演秩不足的 74 维经验协方差。

## 闭合与噪声校准

同模型无噪声数据能恢复注入的 fNL=0、b1=2.42。这个检查验证预测、拟合和参数共享实现，不验证该模型对真实 halo 的物理充分性。

正式拟合权重始终保持 C_single。为了检验 25-phase 均值，在明确假设 phase 独立的条件下，额外使用 C_single/25 生成 500 组相关 Gaussian 噪声。统计量使用两个相关位移组成的二维向量 (b1_joint-b1_P, b1_joint-b1_xi)，而不是只数“是否在两者外面”。

- Gaussian 均值噪声下，约 28.2% 的模拟会让 joint 低于另外两组；仅出现这种排序并不稀奇。
- 当前数据的二维偏移幅度更大：500 次中 6 次的二维统计量至少同样大；加一修正频率约 1.40%，不是精确的显著性测量。
- 再用 25 个实际配对 phase 的去均值残差构造 1000 组 bootstrap 均值噪声，约 32.4% 仍出现向下排序，但 0/1000 次达到当前二维位移统计量。加一结果的 0.10% 是有限模拟分辨率附近的数，不能当成精确 p 值，更不能转换成确定的几 sigma。
- 经验 phase 噪声下整体 joint chi2 的上尾频率约 5.2%，说明参数偏移方向的异常和整体残差平方和是不同问题。

经验 bootstrap 以这 25 个 phase 为条件、会受有限 phase 数和共享观测算子影响；Gaussian 校准则以选定协方差和独立性假设为条件。这两项检验共同支持继续检查平均模型/观测算子的相干残差，但不能单独区分其具体来源。

## 观测算子审计

25/25 个 phase 的 P 和 xi 使用同一份 FKP summary，文件 hash 相同；P0=10000、有效红移逐 phase 一致，模型有效红移 0.6199582457 等于其均值。因此这几项没有发现口径冲突。

xi 从中心值改为 10 Mpc/h 球壳 r² 体积平均，仅使 joint b1 回升约 0.0042。差值网格在直接积分和最终最优点的数值误差远小于 C_single/25 下的 0.001 chi2。本检查不是完整 RR(s,mu) 加权算子。

P 的实际文件只有 ph000 保存了窗口；其余 24 个文件没有窗口矩阵。因此本轮没有进行真实 25-window 平均后的 P 重拟合，也没有把 ph000 的重复使用写成“平均窗口”。这是明确保留的未完成观测算子检验，需要补算缺失窗口。

P 的 LOS 记录为 local，xi 为 midpoint。这是已记录的估计器约定差异，本轮没有证明它造成了当前偏移，也没有计算完整 wide-angle 修正。

P 模型切掉 k<2pi/2000=0.00314159 的理论输入；hybrid FFT 延伸到 1e-5，PNG alpha 在缓存边界外按现有方式延拓。以 fNL=0 的线性 Kaiser 模式估算去掉这些低 k 模式、并同步修正同一个 scalar GIC，局部 b1 响应约 -0.00558。这一小幅且向下的响应不能解释如何把当前 joint 恢复到两者之间；它不是完整非线性 GSM/有限盒长重算。

## 下一步优先级

1. 优先检查 **P0 宽带/常数项与 xi0 预测是否一致**，围绕 50-80 与 220-240 Mpc/h 的 xi0 和较高 k 的 P0 做数据-模型残差与参数响应对照。检查 sn0 的物理归一化、窗口卷积和其与 b1 的补偿关系；不能直接把 sn0 固定成“希望得到的”值。
2. 补算缺失 P 窗口，验证 x25 均值应使用的 P 观测算子；再完善 RR 加权、LOS 与有限盒长约定的统一检验。
3. 若之后要增加模型自由度，应有独立物理动机并通过同一噪声/phase 检验，而不是以“joint b1 是否居中”为调参目标。本轮不继续扩展 GSM。

本轮没有新增独立 halo-matter b1 测量，不能把 P-only b1 自动当作真值。
