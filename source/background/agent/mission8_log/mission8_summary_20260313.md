# Mission 8 总结：离散 shell 对窗口法的解析解释

## 1. 使用口径

- 数据：3Gpc fastPM halo, RSD, fnl=100，与 mission5 保持一致，realization=2..80
- 盒长：L=3000.0 Mpc/h，基模 k_f=2pi/L=0.00209440 h/Mpc
- best-fit P(k) 参数：`fnl_loc=75.697409, b1=2.781936, sigmas=0.015670, p=1.100`
- 窗口法参照：`tanh_log`，参数 `8.0`，并只对 PNG 增量项加窗

## 2. 解析结论

在三维周期盒里，单极相关函数更自然的低-k 表达不是从 `k=0` 开始的连续 Hankel 积分，而是离散 shell 求和：

$$
\xi_0(r)=\frac{1}{V}\sum_q g_q\,\bar P_q\,j_0(k_q r),\qquad k_q=k_f\sqrt{q}.
$$

如果强行写成径向 delta-shell 的连续形式，则需要

$$
P_{0,\mathrm{disc}}(k)=\frac{2\pi^2}{V}\sum_q\frac{g_q\bar P_q}{k_q^2}\,\delta_D(k-k_q).
$$

这说明任务书中设想的“离散 P(k) 用 delta function 建模”是可行的，但系数必须带上 `g_q/k_q^2` 和体积归一化。

## 4. 数值结果

| 方法 | mean|Δ/σ| | chi2/ndof | mean(Δ/σ) |
|---|---:|---:|---:|
| Baseline | 0.5601 | 0.3808 | 0.5601 |
| TestA | 3.4145 | 11.8191 | -3.4145 |
| Window_best | 0.1790 | 0.0367 | -0.0632 |
| ShellHybrid_best | 0.1939 | 0.0702 | 0.1803 |

- 最优 shell hybrid：前 `1` 个非零 shell 作为离散低-k，最后一个离散 shell 为 `q=1`，`k=0.00209440` h/Mpc。
- 这个最优值与窗口法已经非常接近：window 的 mean|Δ/σ|=0.1790，shell hybrid 为 0.1939。
- 但 shell 数量继续增加会迅速变差，说明真正关键的只是最前面极少数离散 shell，而不是把一整段低-k 都离散化。
- `fnl=0` sanity：Baseline 的 mean|Δ/σ|=0.2641；ShellHybrid_best 为 0.2548。

## 5. 对窗口法的解释

从结果上看，**经验窗口法仍然略优于当前最简单的离散 shell hybrid，但两者已经非常接近**。这意味着：

- 仅仅把前若干个最低 shell 离散化，还不足以完全替代当前最佳窗口法；
- 但离散 shell 解析模型已经明确说明，有限盒中真正的低-k 结构不是连续谱，而是很稀疏的离散壳层；
- 因而窗口法之所以有效，更像是在数值上把“从 0 开始的虚构连续 IR 面积”压回到更接近真实有限盒离散 shell 的水平。

更具体地说：

1. `TestA` 把积分下限直接压到 `1e-4` 而不加窗，会明显抬升大尺度 2PCF，说明连续 IR 面积确实在主导偏差。
2. `Baseline` 用 `k_f=2pi/L` 硬切掉低-k 连续部分，可以避免发散，但仍然系统偏低。
3. 窗口法比 Baseline 更好，说明“完全切掉 k<k_f”也过于粗糙；某种受控的低-k 补偿是有必要的。
4. 解析 shell hybrid 说明这种补偿确实应当与有限盒离散模有关；而且最佳情况只需要最前面 1 个 shell，就已经接近最佳窗口法。

## 6. 当前结论

Mission 8 到目前为止，我认为可以下一个比较稳的结论：

> 当前 IR 窗口法之所以有效，核心并不是它具有明确物理意义，而是它在数值上近似模拟了“有限盒低-k 区域本应由极少数离散 shell 贡献，而不是由从 0 开始的连续谱贡献”这一事实。

但与此同时，**简单的离散 shell hybrid 还不能完全替代当前最佳窗口法**。因此若要进一步把 Mission 8 做到更强，需要继续研究：

- 是否应只对 PNG 增量项做离散 shell 化，而不是对总 P(k) 直接做低-k 采样；
- 是否应把每个 shell 的角向结构和 binning 权重更精细地纳入；
- 是否需要在“最后一个离散 shell”和“连续部分”之间引入更平滑的匹配，而不是简单拼接。
