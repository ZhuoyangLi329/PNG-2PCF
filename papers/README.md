# Literature and reference links

The repository stores project notes and stable bibliographic links rather than redistributing third-party PDFs.

1. Chaussidon et al., DESI 2024 VII: Primordial Non-Gaussianity, arXiv:2411.17623, https://arxiv.org/abs/2411.17623
   - Yamamoto/pypower estimator, FKP weights, random-derived window matrix, RIC `W -> W - W_RIC`, and GIC rank-one window term.
2. Brown et al., PNG from LSS 2pcf and 3pcf / ConKer, arXiv:2403.18789, https://arxiv.org/abs/2403.18789
   - Configuration-space spherical-shell convolution and DESI-like mock validation.
3. de Mattia & Ruhlmann-Kleider, Integral constraints in spectroscopic surveys, arXiv:1904.08851, https://arxiv.org/abs/1904.08851
   - Full GIC/RIC density-cross and auto structure.
4. Beutler & McDonald, Window function matrix methods, arXiv:2106.06324, https://arxiv.org/abs/2106.06324
   - Practical survey-window matrix construction.
5. DESI BAO/RSD analysis, arXiv:2404.03002, https://arxiv.org/abs/2404.03002
   - DESI geometry and convolved-theory analysis context.

Project notes mirrored under `source/project/PNG-2PCF-model-to-observe/notes/` summarize the equations and how they map to Task43/Task432 code.
