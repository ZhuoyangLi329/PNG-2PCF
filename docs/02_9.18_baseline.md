# 9.18 baseline 与 9.22 mean-model 对照

## 9.18 baseline

9.18 使用 Task43 的 `FullDiscreteRSDModel`。输入是母盒离散 `k_eff, g_nz, alpha, P_dd`，对每个离散 k 计算 Kaiser × squared-Lorentzian FoG，连续 Gauss-Legendre 积分得到 multipoles，再用 shell-averaged spherical Bessel kernels得到 xi0/xi2。

关键自由参数：

- P-only: `fNL, b1, sigma_s_P, sn0`；
- xi-only: `fNL, b1, sigma_s`；
- joint: shared `fNL,b1,sigma_s` plus P-only `sn0`。

9.18 2PCF 仍是一个从 Fourier multipoles 直接变换得到的模型，RSD 非线性主要由一个常数 `sigma_s` 的 Lorentzian damping 表示。

## 9.22 hybrid

9.22 的 `LightconePNGVelocileptors`/`PNGVelocileptorsGSM` 使用 velocileptors Gaussian CLPT/GSM：

1. 计算 Gaussian density/velocity cumulants；
2. 使用 Gaussian streaming integral 做 real-to-redshift mapping；
3. 在 real-space tracer spectrum 和 density--velocity moment 中加入 `b_PNG(k)=b1+q alpha(k)` 的 leading response；
4. 用 quadrature 得到 xi0/xi2。

它不使用 9.18 的直接 FullDiscrete `j_l` 变换，也不再让 xi-side 拟合 `sigma_s`。最终 trusted hybrid 没有加入独立 `sigma_FOG`；linear-GSM + sigma_FOG 是另一个 diagnostic branch，不能与 formal_mean4 混用。

## 9.22 的限制

- `b2, bs, b3` 与 EFT-like operators 固定为零；
- PNG velocity--velocity response 未加入；
- lightcone hybrid 初始版本在 bin centers 求值，不能自动视为 shell-average；
- xi mean 没有完整 survey window convolution，主要依赖 GIC/RIC operator；
- covariance 仍是 EZmock1000 C_single/full cross，尚未证明等价于 shuffled halo 的物理 scatter。
