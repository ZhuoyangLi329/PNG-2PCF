# 9.30 velocileptors xi full-RIC pipeline

本页说明2026-09-29同步的NERSC现有代码与产物。此次是归档更新，没有重跑科学计算，也没有修改9.22正式模型或结果。

## 状态与数据合同

**正式参考仍是9.22 `full_ric_p02xi02_v1/formal_mean4`。本页所有9.30结果均为 `diagnostic_only`。**

数据沿用25个Abacus halo phase的均值，box-safe `0.4<z_obs<0.8`；P0/P2为13/9点，xi0/xi2各26点，合计74维。P共用kmax=0.08，P2 kmin=0.015；xi采用50≤s<350并去掉80≤s<120。协方差保持EZmock1000的Csingle和完整P-xi cross，不除以25。

早期 `9.30meeting/b1_velocileptors_trial.md` 只将xi换为已有emulator并接旧sn0响应，没有重算该模型自己的完整deterministic RIC。那次joint b1居中是试算现象，不能替代后面的完整算子结果。

## 代码与数据流

科学源文件都位于 `source/project/PNG-2PCF-model-to-observe/codes/task432/`，以下文件名以此为根：

| `task432_joint_b1_velocileptors_diagnostic.py` | 早期xi替换试算 | 仅作历史provenance，不是正式full-RIC入口 |

两个operator目录的完整前缀是：

`source/project/PNG-2PCF-model-to-observe/outputs/task43_outputs/rsd_validation/task432_model_repair/velocileptors_fullric_v1/`

meeting输出的完整前缀是：

`source/project/PNG-2PCF-model-to-observe/9.30meeting/task432_velocileptors_fullric/`

完整xi预测分为：

```text
raw_xi(fNL,b1)
  + xi_response @ GSM_multipoles(fNL,b1)
  + fixed_data_and_random_Poisson_IC
  + sn0 * stochastic_IC_response
```

RIC内部保留233个separation shells，范围0.001–3400 Mpc/h，ell0/2/4，两点Gauss-Legendre r²体积平均；raw拟合xi沿用bin-center评价。NPZ中的`xi_centers`是233个内部shell中心，不能误当成26个拟合bin中心。

GSM baseline中添加最小PNG density及density-velocity response；高阶bias/EFT参数固定零，velocity-velocity保留Gaussian baseline。P侧依旧使用冻结的Kaiser×FoG/full-RIC operator。它不是完整CLPT-PNG模型，也尚未统一P与xi动力学。

## 结果

以直接MAP为cross缩放对比依据：

| fit | b1 | raw chi² |
| --- | ---: | ---: |
| P-only（9.22正式参考） | 2.413459 | 0.894669 |
| xi-only full-RIC | 2.423780 | 2.732121 |
| joint，cross×0 | 2.413786 | 3.758842 |
| joint，cross×0.5 | 2.405968 | 3.490474 |
| joint，cross×1 | 2.378203 | 4.030598 |

full cross恢复后joint中心再次低于两种单独拟合。这个序列说明位移对cross敏感，不证明cross本身错误，也不支持将“居中”当正确性门限。

短链的xi/joint最大概率样本b1分别为2.424813/2.386757，中位数为2.433499/2.387453；这些不是上表的直接优化器MAP。

## 不能省略的限制

- xi/joint仅16 walkers×1200 steps、burn200；局部先验为fNL∈[−100,100]、b1∈[2.3,2.55]，而P曲线复用9.22宽先验正式链。
- 这两条短链使用raw-C likelihood，没有应用正式Hartlap似然与Percival区间处理；不能用图上宽度直接宣称相对正式链的增益。
- xi-only直接MAP的sn0=1触及原先验上界；不能据此声称PLAN的无边界/closure门已全面通过。
- 局部operator的`status=pass`只说明网格编译完成。`smoke_pass`只对应组成与有限值探针，不替代独立random pool、积分收敛、emulator精度、严格MCMC和科学closure门。
- halo的observed-z-resampled random与EZmock公共50x random的完整covariance等价性仍未证明。
- coarse和local入口分别使用不同网格，不能混淆其smoke结果和短链；当前compiler还保留原硬编码网格，`--f-step/--b-step`不应被当作控制local网格范围的可靠接口。
